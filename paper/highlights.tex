\section*{Highlights}

\textbf{PLA: A Transparent, Learnable Rule-Confidence Engine with
Measured Trace Fidelity}

\begin{itemize}
\item A hand-traceable rule-confidence engine with machine-checked convergence
\item Rule and context weights learn via a convex reduction to logistic regression
\item 11 readable rules land 0.01--0.03 below the frontier on real fraud data
\item Pre-registered ablations find no reliable gain from context conditioning
\item Rule-level trace fidelity is measured against reversed and random controls
\end{itemize}
