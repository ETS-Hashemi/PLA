\section{Scenario format}\label{app:scenario}

\begin{verbatim}
{
  "facts": ["PersistentCough", "WeightLoss"],
  "rules": [
    {
      "condition": ["PersistentCough", "WeightLoss"],
      "result": "LungCancerRisk",
      "probability": 0.7,
      "context": {"PatientAge>60": 1.2, "SmokingHistory": 1.5}
    }
  ],
  "queries": ["LungCancerRisk"],
  "contexts": {
    "1": ["PatientAge>60"],
    "2": ["PatientAge>60", "SmokingHistory"]
  }
}
\end{verbatim}

Rule contexts may be flat (weights applying in every set) or nested
(per-set weights, in which the same variable may carry different weights
in different sets); \texttt{"context\_mode": "logit"} selects the
log-odds mode of Section~\ref{sec:context}. Malformed shapes, unknown
sets, and undeclared variables raise \texttt{ScenarioFormatError}.
