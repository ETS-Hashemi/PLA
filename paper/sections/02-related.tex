\section{Related work}\label{sec:related}

\subsection{Probabilistic logic programming}

ProbLog~\cite{deraedt2007} attaches probabilities to logic programs
under the \emph{distribution semantics}: a program denotes a measure over
possible worlds, inference computes exact marginals via knowledge
compilation to weighted Boolean formulas~\cite{fierens2015}, and the
system supports conditioning on evidence, an operation \pla{}
deliberately lacks. (Both capabilities are verified against the
installed \texttt{problog} package by our test suite.) aProbLog
generalizes the semantics to arbitrary commutative
semirings~\cite{kimmig2011}, the natural formal \emph{reference
point} for non-probabilistic confidence calculi, but not an umbrella
that contains \pla{}: G\"odel conjunction does not distribute over
noisy-OR ($\min(0.5,\, 0.4 \oplus 0.4) = 0.5$ while
$(0.5 \wedge 0.4) \oplus (0.5 \wedge 0.4) = 0.64$), so \pla{}'s default
operator pair is not a semiring instance, an executable
counterexample in the repository's semantics document, and one more
sense in which \pla{} trades algebraic structure for hand-traceability. DeepProbLog adds
neural predicates with end-to-end gradient training~\cite{manhaeve2018},
and Scallop compiles differentiable reasoning over provenance
semirings~\cite{li2023}. All of these systems ship as Python packages;
\pla{} claims no language-based novelty whatsoever.

\subsection{Weighted logic and statistical relational learning}

Markov Logic Networks attach real-valued weights to first-order clauses
defining a Markov random field~\cite{richardson2006}; Probabilistic Soft
Logic relaxes truth values to $[0,1]$ with hinge-loss MRFs, making it
the nearest formally grounded cousin of \pla{}'s soft
confidences~\cite{bach2017}; Logical Neural Networks make weighted
real-valued logic differentiable while maintaining truth-value
bounds~\cite{riegel2020}; recent surveys map this converging
territory~\cite{marra2024,garcez2023}, and a 2025 systematic review
charts its current breadth~\cite{colelough2025}. In all of these, rule weights are
\emph{static at inference time}: adapting a rule's reliability to a
changing operational context is retraining's job, not the semantics'.
That gap, context-conditioned weights inside an interpretable
calculus, is the opening \pla{} explores, with two honesty clauses
attached. First, it is an \emph{interface} gap, not an expressivity
gap: the reduction of Section~\ref{sec:learning} shows context
conditioning is exactly rule--context interaction features, which any
fixed-weight system can represent by context-conjoined rules; what
differs is that \pla{} exposes the conditioning in the rule's own
vocabulary and trace. Second, under the drift designs of
Section~\ref{sec:evaluation} the mechanism comes away with a negative
result on its pre-specified endpoint. The connection to the concept-drift
literature~\cite{gama2014}, where adaptation is studied outside
logical representations, survives both clauses. Bayesian networks (e.g.\ the
educational-standard pgmpy package~\cite{ankan2015}) provide
joint-distribution posteriors, verified against the installed package,
but not rule-shaped, trace-first explanations.

A related, newer line uses crisp symbolic solvers to verify the
reasoning of large language models~\cite{pan2023,olausson2023,ye2023},
following the generate-and-verify architecture argued for
in~\cite{kambhampati2024}. A verifier that propagates \emph{uncertain}
rule confidences rather than crisp truth is an open slot in that
architecture which \pla{}-style calculi could fill; we leave this as
future work.

\subsection{Adaptive fuzzy rule systems}

Learnable rule weights have a long history in fuzzy modeling: ANFIS
tunes Takagi--Sugeno rule parameters by gradient descent inside a fixed
network structure~\cite{jang1993}, and the evolving-fuzzy-systems line
adapts rule bases online under drift~\cite{skrjanc2019}. These systems
share \pla{}'s premise that rule strength should be fitted rather than
asserted, and their membership functions face the same
discretization-versus-fidelity tension as our quantile propositions.
They differ in what the rules \emph{say} and how they are audited:
TSK consequents are local functional models rather than
confidence-bearing propositions, aggregation runs through
t-norm/defuzzification pipelines without a named independence stance,
and explanation fidelity is typically not measured. \pla{}'s claim
relative to this line is accordingly not learnability itself but the
trace-first packaging: named aggregation semantics, fitted weights
exported back into the same trace vocabulary, and fidelity measured
against controls.

\subsection{Interpretable rule learning}

A separate line learns compact rule models directly from data: RIPPER's
sequential covering~\cite{cohen1995}, rule ensembles distilled into
sparse linear models (RuleFit~\cite{friedman2008}), Bayesian rule
lists~\cite{letham2015}, certifiably optimal rule lists
(CORELS~\cite{angelino2018}), and additive models with intelligible
shape functions, GA$^2$M and its EBM
implementation~\cite{lou2013,nori2019}. These systems
produce interpretable \emph{classifiers}; \pla{} differs in what
surrounds the rules: an inference engine with named uncertainty
semantics (aggregation operators, symbolic gating), context-conditioned
weights, and traces as the primary output with fidelity measured against
a control. Section~\ref{sec:evaluation} tests against this line
directly: RuleFit, configured as a pure rule ensemble, joins a
depth-limited decision tree and EBM as
interpretable baselines, with all three models' complexity stated
there.

\subsection{Uncertainty calculi: \pla{}'s lineage}

\pla{}'s operators descend from MYCIN's certainty
factors~\cite{shortliffe1975}: rule-attached confidences, attenuation by
the weakest antecedent, Zadeh's G\"odel t-norm~\cite{zadeh1965}, 
and parallel combination of co-supporting rules. Indeed \pla{}'s default
noisy-OR \emph{is} the CF parallel-combination formula
$\mathit{CF} = \mathit{CF}_1 + \mathit{CF}_2(1-\mathit{CF}_1)$, an
equivalence enforced by a unit test. Heckerman showed that the CF
calculus is probabilistically coherent only under restrictive
independence and modularity assumptions~\cite{heckerman1986}, and the
field's retrospective explains the subsequent migration to belief
networks~\cite{pearl1988,heckerman1992}. \pla{}'s response is not to dispute the
critique but to make its subject explicit: it drops the probability
claim entirely (Section~\ref{sec:notprob}), names the independence
stance as a per-knowledge-base operator choice, and provides log-odds
modes that match the likelihood-ratio special case Heckerman identified
as coherent.

\subsection{Positioning: what \pla{} offers, and at what price}

\pla{} does not compete with the systems above on semantic guarantees.
Its offer is four properties, each measured in this paper rather
than promised, that matter precisely when a score must be defended
to a person:

\begin{enumerate}
\item \textbf{Per-decision itemization.} Every score arrives with the
  fired rules, each rule's measured confidence, the explicit
  aggregation arithmetic, and a deletion counterfactual, the
  artifact walked through in Section~\ref{sec:casestudy}, with its
  internal fidelity measured against reversed and random controls in
  Section~\ref{sec:evaluation}. Under distribution semantics this
  artifact is not uniquely determined without an additional
  attribution rule (Section~\ref{sec:notprob}).
\item \textbf{Two-level auditability.} The decision is checkable by
  hand, and so is the system: a few hundred dependency-free lines,
  formal definitions that execute as tests, proved and corroborated
  convergence (Section~\ref{sec:calculus}), and results that
  regenerate from committed scripts (Section~\ref{sec:implementation}).
\item \textbf{Learning that stays in the rule vocabulary.} Rule
  confidences are fitted by a convex reduction to logistic regression
  and export back into the same engine without approximation
  (Section~\ref{sec:learning}), so the learned model itemizes exactly
  like the hand-written one; its calibration is measured against a
  null baseline in Section~\ref{sec:evaluation}.
\item \textbf{Deployment weight.} Zero dependencies and
  sub-millisecond scenario queries (Section~\ref{sec:implementation}),
  against the per-example program compilation of our ProbLog
  evaluation setup (Section~\ref{sec:setup}), a cost of that
  evaluation harness rather than of every ProbLog deployment.
\end{enumerate}

The price is stated with the same precision: no distribution
semantics (Section~\ref{sec:notprob}); ProbLog is the appropriate
choice when possible-world semantics and evidence conditioning are
required; and a measured accuracy gap of $0.002$--$0.034$ AUC
per split to the interpretable frontier on the credit-card study
(Section~\ref{sec:evaluation}). The intended domains are education and
audit-style settings~\cite{appelbaum2017}, where inherent
interpretability is a requirement, not a
preference~\cite{rudin2019,jacovi2020}, and where fraud-detection
practice~\cite{west2016,dalpozzolo2015,bao2020} supplies public data
for evaluation.
